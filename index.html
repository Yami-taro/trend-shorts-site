Trend Shorts

A small personal tool that creates one original short video a day about a trending topic, and uploads it to its owner's own YouTube channel.

How it works

  1. Reads the list of popular videos from the public YouTube Data API to see which topics are trending.
  2. Writes an original script about one topic (facts, news and context, never copied footage).
  3. Turns the script into a vertical video with captions and a computer voice.
  4. Uploads that one video to the owner's channel with the YouTube upload API.

Who can use it

Only its owner. It is not a public service, it does not have other users, and it only uploads to the channel that its owner signs in with.
