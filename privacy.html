Privacy Policy

Trend Shorts · Last updated: October 26, 2026

Trend Shorts is a personal tool used only by its owner. It creates one original short video a day about a trending topic and uploads it to the owner's own YouTube channel. This page explains what data it uses.

Data it uses

  • Public YouTube data: titles, view, like and comment counts of popular videos, read from the YouTube Data API to find trending topics.
  • Permission to upload: when the owner signs in with Google, the tool receives a token that lets it upload videos to the owner's channel (scope: youtube.upload). It cannot read the owner's email, other Google data, or private videos.

How the data is stored and shared

  • The upload token is stored only in the owner's private, encrypted settings. It is never shared, sold, or published.
  • No data about any other person is collected. The tool has no other users and no analytics or tracking.
  • Videos are sent only to YouTube, through the official YouTube API.

YouTube API Services

This tool uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions. The stored token then stops working, and it is deleted from the tool's settings.
